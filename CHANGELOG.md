# Changelog

All notable changes to the NovaStore platform are documented in this file.

## [v1.5.0] - 2026-09-06

### Features & Fixes
- **Coupons**: Enforced strict 1-time coupon usage limit per customer with Redis cart clearance.
- **Products**: Safe variant reconciliation preserving order foreign keys and slug collision handling.
- **Invoice**: Added authentic royal blue cursive signature (`M. Kumar`) and Authorized Signatory block.
- **UI/UX**: Added Indian currency formatters, PIN code validators, empty states, and debounced search hooks.
- **Architecture**: 50 continuous modular iterations improving types, utilities, configurations, and documentation.
