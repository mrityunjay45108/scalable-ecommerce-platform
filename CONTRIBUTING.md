# Contributing to NovaStore Platform

## Development Workflow
1. Install dependencies: `pnpm install`
2. Start dev environment: `pnpm run dev`
3. Check types: `pnpm run type-check`
4. Run tests: `pnpm run test`

## Commit Conventions
All commits should follow conventional commits:
- `feat(...)`: New features
- `fix(...)`: Bug fixes
- `chore(...)`: Maintenance, refactoring, and project improvements
- `test(...)`: Unit and integration tests
